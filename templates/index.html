Project Overview
About PhishGuard

PhishGuard is a machine-learning-based phishing website detection system developed as a cybersecurity and machine-learning portfolio project. It analyzes the characteristics of a submitted URL without opening the website.

Detection Model
V5 Linear Support Vector Machine
Feature Representation
Character-level TF-IDF + 17 numerical URL features
Web Framework
Python + Flask
Probability
Validation-set calibrated SVM output
Dataset
UCI PhiUSIIL Phishing URL Dataset
Developer
Joar Cristobal
PhishGuard is a research prototype. Its prediction represents the model's assessment of URL characteristics and should not be treated as definitive proof that a website is safe or malicious.
Detection Pipeline
How PhishGuard Works

Every submitted URL passes through a sequence of local processing and machine-learning stages before the application produces a final security assessment.

01

URL Input

The user submits a website URL through the Flask application.

02

Feature Extraction

Character-level TF-IDF and 17 numerical URL characteristics are generated from the submitted URL.

03

V5 Linear SVM

The combined URL representation is evaluated by the V5 Linear SVM to produce a classification decision score.

04

Calibration & Risk Assessment

The SVM decision score is calibrated into a probability estimate and passed to the risk assessment system.
